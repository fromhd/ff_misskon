# ff_misskon

MissKon.com viewer/downloader plugin based on `ff_4khd`.

## Features

- Latest post list
- Top 3/7/30/60 day pages
- Search
- Detail viewer for images, videos, and external download links
- Optional image proxy
- JPG + ZIP download

## Setting

- `misskon_url`: default `https://misskon.com`
- `download_path`: download output path
- `proxy_enabled`: proxy images through the plugin route
